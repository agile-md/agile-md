## Notes

The backlog view is only required when managing existing tickets not on the board. And the done view is work completed. Most activity is with tickets in scope to be done or doing so the board is cleaner if these two comumns are collapsable.
By default only the backlog should be collapsed but the Done view should be collapsable.

## Acceptance criteria

- When the board is opened the Backlog view should be collapsed horrizontally [ ] 
- When the board is opened the Done view should be visible [ ] 
- When the backlog view pulled out the backlog tickets should be visible [ ]
- When the done column is collapsed the done tickets should not be visable [ ]
- The collapsed columbs should be able opened by pulling horizontally towards the centre of the board [ ]
The collapsed views should have a thin tripple line edge closest to the centre of the board that the user can pull to open the view.
