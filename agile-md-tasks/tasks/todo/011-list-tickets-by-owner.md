## Notes
There should be a tab that shows all the tickets assigned to an owner.
The default should be to show the tickets assigned to the current owner.
It should be possible to select a different user and display tickets owned by that user.
It should be possible display all unnasigned tickets.

## Acceptance criteria

- [
- when a user entres the tickets tab they should see tickets assigned to them across all the repositories.
- Tickets should be ordered by priority with the highest priority at the top.
- Tickets in progress should be listed higher than other tickets of the same priority.
- When a user selects an owner from the owner dropdown they should see tickets of that owner.
- When a user selects unassigned from the owner selection dropdown they should see all the unassigned tickets.
]
